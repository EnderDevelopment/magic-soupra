# Magic Soupra — Open Source Interactive Power Selection UI

Magic Soupra is an open source interactive web interface for selecting elemental powers, featuring a dark fantasy power menu, responsive frontend layout, animated Canvas 2D particles, dynamic power descriptions, control and intensity indicators, and interactive visual effects for fire, water, wind, spirit, steam, shadow, stone, and cosmos.

## Install

1. Download or clone the project.
2. Make sure `index.html`, `styles.css`, and `app.js` remain in the same directory.
3. Start a local web server from the project directory. For example, with Python:

```bash
python3 -m http.server 8000
```

4. Open `http://localhost:8000` in a modern web browser.

The interface uses Google Fonts through external stylesheet links. An internet connection is recommended for loading the Cinzel and Inter fonts.

## Use

1. Open the application in a modern browser.
2. Select one of the eight power cards:
   - Fire
   - Water
   - Wind
   - Spirit
   - Steam
   - Shadow
   - Stone
   - Cosmos
3. Review the selected power’s description, control value, and intensity value.
4. Move the pointer across the page to create Canvas particle effects.
5. Click “AWAKEN POWER” to trigger a larger particle burst and a confirmation toast.
6. Resize the browser window to view the responsive desktop and mobile layouts.

The project is a frontend interface and does not include a backend, authentication, persistence, game logic, or real elemental abilities.
